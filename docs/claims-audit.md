# Wired-or-cut audit

Task 5.1. Every tool, model and vendor named on a judge-facing surface, traced to the code that
imports or calls it. A claim with no import is cut or reworded; the table is regenerated by hand
whenever a surface changes, and `api/tests/test_claims.py` holds the surfaces to what
`/api/status` reports at runtime.

Surfaces audited: `README.md`, `JUDGE.md`, `AGENTS.md`, `.env.example`, the Devpost project
description and its Built With tags.
