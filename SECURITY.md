# Security

## Reporting

Open a [private security advisory](https://github.com/StephenSook/hold/security/advisories/new).
Please do not open a public issue for a vulnerability.

Expect a first reply within three days. This is a hackathon project with a small team, so that is
a realistic number rather than an aspirational one.

## What this service is

One Cloud Run instance serving a React app and a FastAPI API from the same origin. Every route
under `/api` is unauthenticated **on purpose**: the whole point is that a judge can check the
claims without an account. There is no user data, no login, and no database. The only state is a
job store in process, which is lost on restart.

That shapes what counts as a vulnerability here:

**In scope.** Anything that reads a file outside `web/dist` through the static route, anything
that makes the instance serve or execute attacker-controlled content, resource exhaustion that
takes the origin down, and anything that causes the service to state something false about
itself, because the claims are the product.

**Out of scope.** Missing authentication on `/api` routes, which is the design. Rate limiting,
which Cloud Run provides at the edge. The absence of CSRF tokens on an API with no sessions.
Reports generated by a scanner with no demonstrated impact.

## What is already tested

- `api/tests/test_static_containment_props.py` attacks the static route with generated path
  segments: traversal at any depth in both separator styles, encoded separators, null bytes,
  unicode homoglyphs, symlinks pointing in and out, and directories. The property asserted is
  that whatever comes back is a regular file inside the build directory, or nothing does.
- `api/tests/test_claims.py` holds every judge-facing surface, including the architecture
  diagram, to naming only what `/api/status` reports.
- `gitleaks` and Socket run on every push. No key exists in the repository or its history:
  deploys authenticate through Workload Identity Federation and secrets live in Secret Manager.
- `docs/THREAT_MODEL.md` is the longer version of this page.

## Dependencies

`scripts/check_licenses.py` fails the build on a copyleft or source-available dependency.
`docs/THIRD_PARTY_NOTICES.md` is generated and lists every dependency with its copyright holder.
