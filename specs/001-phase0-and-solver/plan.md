### Task 1.3: CP-SAT benchmark model (solver-engine mode)

Files created:
- `api/hold/model.py` - the benchmark CP-SAT model

Shape locked by PLAN.md task 1.3 and Decisions D1-D3:

**Variables:**
- `pos: list[IntVar]` - position of each scene in the schedule (domain 0..num_scenes-1)
- `scene_at: list[IntVar]` - scene at each position (inverse of pos; domain 0..num_scenes-1)
- `AddInverse(pos, scene_at)` plus `AddAllDifferent(pos)` (belt-and-suspenders; AddInverse implies AllDiff but the explicit constraint aids propagation)
- Per actor j: `first_j: IntVar` (domain 0..num_scenes-1), `last_j: IntVar` (domain 0..num_scenes-1)
- Per actor j, per scene i not in ia[j]: `onset[j][i]: BoolVar` (1 iff scene i is between first_j and last_j inclusive)

**Constraints:**
- `first_j <= pos[i]` for all i in ia[j] (actor's first work scene)
- `pos[i] <= last_j` for all i in ia[j] (actor's last work scene)
- `onset[j][i] == 1` iff `first_j <= pos[i] <= last_j` (reified via AddMaxEquality / linear reification: `pos[i] >= first_j` and `pos[i] <= last_j` both hold iff onset is 1; use the standard CP-SAT reification pattern with indicator literals)
- When `symmetry_break=True`: one symmetry-breaking constraint on the benchmark model; shape TBD at implementation (e.g. lexicographic ordering on a subset of positions for equivalent actors)

**Objective:**
- `holding = sum over j, over i not in ia[j]: c[j] * d[i] * onset[j][i]`
  - All coefficients `c[j] * d[i]` are constant integers, so this is a linear objective over BoolVars
- `fixed = sum over j, over i in ia[j]: c[j] * d[i]` (constant, computed from Instance)
- `total = holding + fixed`
- Minimize `holding` (the variable part; minimizing holding minimizes total since fixed is constant)
- `symmetry_break: bool` parameter passed to the function

**Solve parameters:**
- `CpSolverStatus.OPTIMAL` required
- Measure wall-clock solve time per instance
- Returns `(status, holding_value, total_value, solve_ms)`

- `api/tests/test_model_smoke.py` - solves film116 with `symmetry_break=False`; asserts `status == OPTIMAL`, `holding == 110`, `total == 541`; records solve_ms in a print statement (not an assertion, since timing varies by machine)

Mode: solver-engine (matches `api/hold/`, `api/tests/`).

Done means: film116 OPTIMAL, holding 110, total 541; times recorded in Notes in PLAN.md.

### Task 1.5: Independent checker (solver-engine mode)

Files created (extends `api/hold/checker.py` started as a placeholder; fuller implementation here):
- `api/hold/checker.py` - plain Python, no OR-Tools:
  - `check_permutation(instance: Instance, perm: list[int]) -> CheckResult` where `CheckResult = (holding: int, total: int, valid: bool, error: str | None)`
  - Validates that `perm` is a valid permutation of range(num_scenes)
  - Recomputes `first_j` and `last_j` for each actor from the permutation
  - Recomputes holding as `sum_j c_j * sum_{i not in ia[j], first_j <= perm.index(i) <= last_j} d_i`
  - Recomputes total as holding + fixed
  - A corrupted permutation (duplicate scene, wrong length, out-of-range index) returns `valid=False`
- `api/tests/test_checker.py` - asserts checker agrees with solver on all 8 medium instances (uses optimal permutation from the solver); asserts checker rejects a permutation with a duplicate scene id; asserts checker rejects a permutation of wrong length

Mode: solver-engine.

Done means: Green.
